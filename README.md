# Ryn Pro — بوت تداول Binance الذكي السريع + شات محلل السوق المحترف

نسخة مطوّرة بالكامل تفصل بين **محرك التداول الآلي فائق السرعة** وبين **الذكاء الاصطناعي (محلل السوق)**:

1. **تداول خوارزمي فوري ومستقل 100% عن الذكاء الاصطناعي**:
   - يراقب السعر كل **ثانيتين** (`POLL_SECONDS=2`) مع كاش ذكي للشموع لتفادي التأخير السعري (Slippage).
   - يلتقط القاع لحظة توقف الهبوط ويشتري فوراً بسعر العرض الفعلي (`Ask`) دون انتظار رد نموذج الذكاء الاصطناعي.
   - يحسب **سعر التكلفة الفعلي شامل العمولة** (`actual_entry_price`) ليطابق سعر التكلفة الحقيقي في محفظة Binance.
   - ينفذ البيع الفوري عند الهدف، مع ميزة **حماية الربح الذكية (Trailing Profit Lock)** إذا اقترب السعر من الهدف ثم عكس اتجاهه، ومعالجة دقيقة لفلاتر `LOT_SIZE` و`stepSize` لبيع الكمية الكاملة دون اقتطاع خاطئ.
   - أزرار تحكم يدوي فوري في اللوحة: **شراء فوري بسعر السوق**، **بيع فوري الآن**، و**تحديث السعر المرجعي**.

2. **شات المتداول المحترف ومحلل السوق (Ryn Pro Analyst)**:
   - دور الذكاء الاصطناعي (عبر Groq) مخصص حصرياً للشات والاستشارة الفنية.
   - يقرأ المؤشرات الفنية الحية المحسوبة لحظياً من الشموع: **RSI (14)**، المتوسطات المتحركة **EMA 9 / EMA 21 / EMA 50**، **أقرب مناطق الدعم والمقاومة**، واتجاه السوق العام واللحظي.

## الإعداد على Render (Environment)
- `EXCHANGE_API_KEY` و `EXCHANGE_API_SECRET` : مفاتيح Binance
- `GROQ_API_KEY` : لتفعيل شات محلل السوق المحترف
- `APP_PASSWORD` : كلمة سر اللوحة (إلزامية في الوضع الحقيقي `live`)
- `TRADING_MODE` : `testnet` (تجريبي) أو `live` (حقيقي)
- `POLL_SECONDS` : سرعة الفحص بالثواني (الافتراضي `2`)
- `MEMORY_FILE_PATH` : مثلاً `/data/ryn_memory.json`
